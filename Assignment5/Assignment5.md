# CS 601.471/671: Self-supervised Models
## Assignment 5: A GPT Language Model from Scratch

### Overview
In this assignment, we will:
- implement our own GPT - Transformer-based language model.
- learn about how to run Slurm jobs to train and evaluate the GPT LM on GPUs
### Setup
create a new environment for this assignment:
```
conda create -n ssm_assignment5 python=3.10.13
```

And install the required packages:
```
cd Assignment5
conda activate ssm_assignment5
pip install -r requirements.txt
```

### Run the code
Once you have finished each part of the assignment, uncomment the corresponding lines in `main.py` to run it.
